## 1. Architectural Overview

The AgroStruxure presentation engineering pipeline implements a production-grade frontend slide delivery model. Rather than relying on static slides generated by LLM slide tools or generic template packs, the AgroStruxure deck is an engineered web application built on modern web standards, adhering to:

1. **Brand Authority:** `DESIGN_SYSTEM.md`
2. **Layout Discipline:** `frontend-slides` fixed 1920×1080 stage architecture
3. **Typography & Hierarchy:** Poppins (Headings) / Inter (Body) / JetBrains Mono (Telemetry)
4. **Export Automation:** Headless Chrome screenshot capture pipeline, PIL multi-page PDF compiler, and `python-pptx` widescreen 16:9 packaging.

## 3. Responsive 16:9 Stage Architecture

Following the `frontend-slides` specification, the deck lives inside a fixed coordinate system (`1920 × 1080 px`) that dynamically scales to fill any browser viewport while preserving an exact 16:9 aspect ratio:

```javascript
function scaleStage() {
  const stage = document.getElementById('presentation-stage');
  const windowWidth = window.innerWidth;
  const windowHeight = window.innerHeight;
  
  const scaleX = windowWidth / 1920;
  const scaleY = windowHeight / 1080;
  const scale = Math.min(scaleX, scaleY);
  
  stage.style.transform = `translate(-50%, -50%) scale(${scale})`;
}
```

### Benefits:
- **Pixel Perfection:** Typography never reflows, cards never break, and layout margins remain mathematically identical regardless of display resolution (1080p, 1440p, 4K, or mobile).
- **Presentation Mode:** Supports fullscreen display (`F11`), keyboard arrows (`Left`, `Right`, `Space`, `PageUp`, `PageDown`), and direct number keys (`1` through `0` for slide 10).

## 4. Visual Asset Integration

To ensure the HTML file is 100% self-contained, portable, and offline-functional, all visual media assets are base64-encoded as data URIs within `presentation.html`:
